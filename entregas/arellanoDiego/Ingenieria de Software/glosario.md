# Glosario del Modelo del Dominio

| Término | Definición |
| :--- | :--- |
| **Estudiante** | Persona que asiste a las clases y recibe calificaciones por su desempeño en las evaluaciones. |
| **Profesor** | Persona encargada de dirigir las clases y asignar las calificaciones a los estudiantes. |
| **Asignatura** | Materia académica oficial en la que participan estudiantes y profesores. |
| **Sesión de clase** | Encuentro organizado donde el profesor comparte el contenido de la materia con los estudiantes. |
| **Repositorio** | Espacio institucional donde se guardan los documentos y materiales del curso para su consulta. |
| **Temario** | Conjunto de contenidos que define los temas a tratar en la asignatura. |
| **Evaluación** | Actividad o prueba que mide el aprendizaje del estudiante. |
| **Evaluación continua** | Tareas y actividades regulares que representan una cuarta parte (25%) del resultado final. |
| **Examen parcial** | Prueba a mitad del curso que representa una cuarta parte (25%) del resultado final. |
| **Examen final** | Prueba global de cierre que representa la mitad (50%) del resultado final. |
| **Nota final** | Calificación total que determina si el estudiante supera o no la asignatura. |
